# Pin Mapping

## Ultrasonic Sensors

| Sensor | TRIG | ECHO |
|---|---:|---:|
| Slot 1 | D2 | D3 |
| Slot 2 | D4 | D5 |
| Slot 3 | D6 | D7 |
| Slot 4 | D8 | D9 |

## Indicators

| Component | Pin |
|---|---:|
| Green LED | D10 |
| Red LED | D11 |
| Buzzer | D12 |

## LCD

| LCD | Arduino UNO |
|---|---|
| SDA | A4 |
| SCL | A5 |
| VCC | 5V |
| GND | GND |

## Servo

| Servo | Arduino UNO |
|---|---|
| Signal | A0 |
| V+ | 5V |
| GND | GND |
