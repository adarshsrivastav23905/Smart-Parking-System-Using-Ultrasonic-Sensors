# 🧪 Wokwi Simulation

The complete Smart Parking System is simulated using Wokwi.

## Simulation Components

- ESP32 DevKit
- 4 × HC-SR04
- SSD1306 OLED
- 8 LEDs
- Buzzer
- SG90 Servo

## Running the Simulation

1. Open the project in VS Code.
2. Open the root `diagram.json`.
3. Start Wokwi.
4. Start the simulation.
5. Change the distance value of each HC-SR04.
6. Observe the OLED and LEDs.
7. Test the parking-full condition.
8. Observe the servo.
9. Open the web dashboard.
