SMART PARKING SYSTEM
PARKING STATUS LOGIC
====================

DETECTION RULE
--------------
Distance < 35 cm
    → OCCUPIED

Distance >= 35 cm
    → FREE


FREE SLOT
---------
Slot State   : FREE
Green LED    : ON
Red LED      : OFF


OCCUPIED SLOT
-------------
Slot State   : OCCUPIED
Green LED    : OFF
Red LED      : ON


SPACE AVAILABLE
---------------
Condition    : Available Slots > 0
System       : SPACE AVAILABLE
Gate         : OPEN
Buzzer       : OFF


PARKING FULL
------------
Condition    : Available Slots = 0
System       : PARKING FULL
Gate         : CLOSED
Buzzer       : ON
Green LEDs   : OFF
Red LEDs     : ON


EXAMPLE STATES
--------------

4/4 AVAILABLE
-------------
S1 = FREE
S2 = FREE
S3 = FREE
S4 = FREE
Gate = OPEN
Buzzer = OFF


2/4 AVAILABLE
-------------
S1 = OCCUPIED
S2 = FREE
S3 = OCCUPIED
S4 = FREE
Gate = OPEN
Buzzer = OFF


0/4 AVAILABLE
-------------
S1 = OCCUPIED
S2 = OCCUPIED
S3 = OCCUPIED
S4 = OCCUPIED
Gate = CLOSED
Buzzer = ON


SLOT RELEASE
------------
Example:
20 / 20 / 20 / 20
        ↓
20 / 20 / 20 / 80

Result:
Available = 1/4
Buzzer = OFF
Gate = OPEN
